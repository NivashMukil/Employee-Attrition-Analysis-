# HR Attrition Analysis

## 📌 Project Overview
This project analyzes HR employee data to identify key factors contributing to employee attrition. The goal is to uncover patterns and insights that help organizations improve employee retention and make data-driven HR decisions.

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 📊 Dataset Information
- Total Records: 49,000+ employees
- Data includes employee demographics, job roles, salary, experience, and attrition status

## 📊 Key Tasks Performed
- Data cleaning and preprocessing (handling missing values, data validation)
- Feature engineering (experience calculation, data transformation)
- Exploratory Data Analysis (EDA)
- Correlation analysis to identify key factors affecting attrition

## 📈 Key Insights
- Higher attrition observed among employees with lower job satisfaction
- Employees with less experience showed higher attrition rates
- Certain job roles had significantly higher attrition trends
- Salary and work experience played a major role in employee retention

## 📷 Visualizations
- Attrition distribution charts
- Age vs Attrition analysis
- Job role-based attrition graphs
- Correlation heatmap
